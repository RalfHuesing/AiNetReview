# Roadmap: initial infrastructure implementation

Implement the [ready concept](Konzept.md) against the [approved product concept](../initial-infrastructure/AiNetReview-Konzept.md) and its four epics. Each implementation item is one agent session: inspect the actual repository state and any applicable AiNetLinter reference specified in Epic 4, implement the stated scope, run the relevant checks, update affected current-state documentation, close its checkbox, and commit only that verified slice. The linked contracts define all fields, edge cases, and exclusions; this roadmap sets order and acceptance, not new product behavior. Complete the items in each milestone in order before starting the next.

Acceptance: focused tests cover strict JSON and path validation, option defaults, invalid and duplicate descriptors, safe rule IDs, and the productive versus test-only registration boundary; the affected build and tests pass.
- [x] **Load a complete immutable Roslyn solution.** Intention: give every rule one consistent source view. Scope: solution loading, source materialization, project and path boundaries, compilation checks, and failure mapping from [Epic 1](../initial-infrastructure/epics/01-Eingaben-und-Host.md); use the AiNetLinter loader reference under [Epic 4](../initial-infrastructure/epics/04-Umsetzung-und-Abnahme.md#ainetlinter-als-referenz). Not included: persisted snapshots or rereading sources during rule execution. Acceptance: integration tests cover `.sln` and `.slnx`, a Git-less project, path escape, missing references, load and compilation failure, and source mutation after load; the affected build and tests pass.

  Verification (2026-09-28): `pwsh -File ./scripts/build.ps1` succeeded with 0 warnings and 0 errors; `pwsh -File ./scripts/test-integration.ps1` passed 18/18 tests. - [x] **Run rules and validate current findings.** Intention: make a complete empty result distinguishable from incomplete analysis. Not included: finding history, stored identity, verdicts, or report formatting.
