# Relaunch-Diskussion

Für einen neuen Chat zuerst das unveränderte [Relaunch-Konzept](Relaunch-Konzept.md) als Motivation und dann das [AiNetReview-Konzept](AiNetReview-Konzept.md) lesen. Die dort verlinkten vier Epics enthalten die verbindlichen Verträge und das DoD. Jeder Vertrag steht nur an einer Stelle; bei Änderungen werden überholte Aussagen ersetzt und betroffene Querverweise geprüft.

Dieses Task-Verzeichnis gehört zum neuen Repository `C:\Daten\Entwicklung\Ralf\AiNetReview\`. Der vorhandene, getestete AiNetLinter-Code liegt im **anderen** Repository `C:\Daten\Entwicklung\Ralf\AiNetLinter\`. Die Quellcode-Vorlagen in Epic 4 beziehen sich auf diesen absoluten Pfad. Umsetzung und neue Dateien gehören ausschließlich in AiNetReview.

Der Agent nennt bei Architekturfragen seine Empfehlung mit Begründung und weist auf Sackgassen hin. Er hält die Spezifikation bis zum definierten DoD vollständig: keine offenen Varianten oder ungelösten Produktfragen. Änderungen werden im zuständigen Epic nachgeführt. Das ursprüngliche Nutzerkonzept bleibt unangetastet. Diese README beschreibt ausschließlich den Gesprächs- und Dokumentationsablauf.
